# 💧 Water Station Sales & Inventory Manager / Gestor de Recargas de Agua

A C++ CLI application designed for real-time inventory tracking, cash and credit sales management, multi-currency conversions (USD/VES), and debt management[span_0](start_span)[span_0](end_span).
*Sistema de consola en C++ diseñado para el control de inventario en tiempo real, gestión de ventas de contado/fiadas, conversión multimoneda (USD/VES) y seguimiento de clientes deudores[span_1](start_span)[span_1](end_span).*

---

## 🛠️ Key Backend Concepts Applied / Conceptos Aplicados
- **Custom Data Models:** Utilization of `struct Venta` for complex transaction management[span_2](start_span)[span_2](end_span).
- **Dynamic Memory Collection:** Usage of `std::vector` for memory-based transaction history[span_3](start_span)[span_3](end_span).
- **Modular Programming:** Separation of business logic into functions and procedures with pass-by-reference (`&`) optimization[span_4](start_span)[span_4](end_span).
- **CLI Data Flow:** Interactive menu controls, input validations, and status alerts[span_5](start_span)[span_5](end_span).
